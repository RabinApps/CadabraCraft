## Workflow

Work milestone by milestone, one PR each, with tests and docs. Ideas outside the current milestone go in [docs/roadmap.md](docs/roadmap.md). Architecture decisions, with rejected alternatives, go in [docs/architecture.md](docs/architecture.md). See [CLAUDE.md](CLAUDE.md) for the repo rules and [README.md](README.md) for the layout and commands.
